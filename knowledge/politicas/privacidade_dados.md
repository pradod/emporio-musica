# Privacidade e proteção de dados (LGPD)

A loja segue a Lei Geral de Proteção de Dados (Lei nº 13.709/2018). Os dados pessoais (nome, telefone, e-mail, endereço) são usados só para:
- processar e entregar pedidos;
- informar status e rastreamento de pedidos;
- enviar promoções e novidades, **apenas com consentimento explícito**;
- cumprir obrigações legais e fiscais.

Os dados não são compartilhados com terceiros para marketing. O cliente pode pedir a exclusão dos seus dados a qualquer momento pelo WhatsApp ou e-mail.

No atendimento, dados de pedidos só são informados após confirmar o número do pedido junto com o telefone ou e-mail do cadastro.
